Snake Game 🐍

A classic Snake Game recreated using vanilla HTML, CSS, and JavaScript. Players control a growing snake, collect food to increase their score, and avoid collisions with walls and themselves. The project focuses on core game development concepts such as game loops, keyboard controls, collision detection, DOM manipulation, and state management.

Features include -

Smooth keyboard controls, Random food generation, Real time score tracking, Self collision detection, Restart game functionality, Start game screen, Responsive design and is built using pure JavaScript without external libraries

Technologies Used -

HTML5, CSS3, JavaScript (ES6)

This project was created to practice JavaScript game development fundamentals and improve problem solving skills through interactive programming.
